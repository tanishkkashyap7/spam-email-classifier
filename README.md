# 📧 Spam Email Classifier

<p align="center">
  <img src="assets/banner.png" alt="Spam Email Classifier Banner" width="100%">
</p>

<h3 align="center">
Machine Learning Based Spam Detection System using NLP & Scikit-learn
</h3>

<p align="center">
This project classifies emails/messages as Spam or Ham (Not Spam) using Natural Language Processing and Machine Learning techniques.
</p>

---

## 🚀 Features

- 📩 Spam vs Ham classification
- 🧠 NLP text preprocessing
- 🔍 TF-IDF vectorization
- 🤖 Machine Learning model training
- ⚡ Real-time prediction
- 📊 High accuracy spam detection
- 🐍 Python-based implementation

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/tanishkkashyap7/spam-email-classifier.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd spam-email-classifier
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
python app.py
```
